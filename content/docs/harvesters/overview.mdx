## 🔍 How Harvesters Work

When you run `npx qodewk`, the engine performs the following multi-step pipeline:

1. **Discovery:** Scans standard system paths across Windows, macOS, and Linux for active agent sessions belonging to the current Git repository or workspace directory.
2. **Footprint Extraction:** Reads session databases, JSON lines, and metadata without modifying or altering local state.
3. **Git Correlation:** Inspects the Git commit history and working tree diff to associate agent tool executions (`write_to_file`, `replace_file_content`, `Edit`, `Write`) with specific line changes.
4. **Token Accumulation:** Sums input tokens, cached/read tokens, output tokens, and tool call counts across all multi-turn conversation rounds.
5. **Cost Calculation:** Maps harvested model IDs against `@qodewk/pricing` rate cards to calculate exact dollar amounts.
