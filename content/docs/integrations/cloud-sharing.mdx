# Cloud Sharing & Receipts

Publish receipts to Qodewk Cloud with a single command:

```bash
npx qodewk share
```

### Key Features:
- Short, memorable URLs: `https://qodewk.dev/r/rec_...`
- High-fidelity visual cards for Slack, Discord, and X (Twitter).
- Interactive token breakdown and contribution pie charts.
