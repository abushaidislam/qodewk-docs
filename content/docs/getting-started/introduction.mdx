# Qodewk — Proof of Shipment for the AI Coding Agent Era

**Qodewk** is a universal developer telemetry engine and digital receipt generator designed for the autonomous software development era. It harvests local footprints left by AI coding agents (**Google Antigravity**, **Claude Code**, **Cursor**, **Aider**, **Copilot**), cross-references them with your repository's Git revision history, and generates verifiable, privacy-safe **Proof of Shipment** receipts.

## 💡 Why Qodewk?

As AI coding agents take over daily programming workflows, engineering leaders and developers face three critical challenges:

1. **Attribution Blindspots:** Who wrote which part of this 500-line Pull Request? Was it human or autonomous agent?
2. **Invisible Frontier AI Cost:** How much did that feature branch really cost across input tokens, output tokens, and prompt caching?
3. **Multi-Platform Fragmentation:** Developers use Google Antigravity for complex tasks, Claude Code CLI in terminal, and Cursor IDE for daily editing. Single-vendor telemetry tools cannot connect the dots.

Qodewk unifies multi-platform agent footprints into a single, standardized **Receipt Protocol (Receipt v1.0)**.
